# EBAC Jobs — Styled Components (Tema Alternativo)

**Autor:** Josué Beuren  
**Exercício:** EBAC — CSS in JS (Styled Components)  
**Data:** 2025-10-29

## O que foi feito
- Conversão completa para **Styled Components** dos componentes:
  - Cabeçalho (Cabecalho)
  - Formulário (FormVagas)
  - Hero
  - Vaga
  - ListaVagas
- Remoção de todos os arquivos **.module.css** (não usados após a conversão).
- Manutenção do tema **alternativo** (cores quentes: areia/sálvia/cobre) e **fontes**
  - **Work Sans** (texto) e **Crimson Text** (títulos).
- Responsividade, foco/hover acessíveis e pequenos ajustes de contraste.

## Como rodar
```bash
npm install
npm start
```

## Observações
- Projeto em React + TypeScript com Styled Components.
- Variáveis de cor e ajustes de tipografia estão em `src/global.css` e `public/index.html` (fontes).
- Você pode adaptar as cores alterando as variáveis `:root`.
